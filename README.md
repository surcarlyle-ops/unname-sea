# 未名之海 (The Unnamed Sea)

> 一款战斗与移动手感优先的单人第一人称 3D 自由实时动作 RPG。钓鱼暂作未知收获与装备成长入口；用简单场景先做 5—10 分钟可玩 MVP，正式人物和丰富美术后置。（Codex）

**现行设计**：[GDD](docs/GDD_未名之海.md)（2026-10-20）。第一人称自由战斗；武器暂自带技能，与遗物共鸣和小幅永久收集增益并存，取消天赋树。左上五格 1—5 快捷物品位自由配置；专业药水主要购买，食物可自制。钓鱼节奏改为对标《泰拉瑞亚》，代码尚待迁移。（Codex）

**当前实现**：默认进入第一人称移动练习，自动奔跑、Shift 走路、Ctrl 蹲／滑铲，支持翻越／攀爬和钩爪。自有皮手套已接入从成熟近战资源适配的逐指握剑姿势，按 1 查看；当前并行版本默认选择手枪。握持专项 21/21；旧手部 28/29（空手启动断言不符），战斗 36/41，关闭新握姿仍复现同样 5 项失败；旧移动 56/63 未重测。详细状态与缺口见 CHECKPOINT，完整 MVP 闭环未完成。（Codex）

**现用与历史角色**：第一人称使用自有棕色露指手套与布袖，每只 22 骨，模型／贴图不变；`assets/characters/fps_gloves/sword_grip_pose.json` 保存适配后的剑握姿，`authoring/glove_sword_grip.blend` 为可编辑工程。按 1 持剑、2 空手；尚未迁移模板整套挥砍，观感待用户验收。旧第三人称原创 Tripo 新来者在 `assets/characters/newcomer_tripo/`；穹模型仅供本地历史参考，不纳入 Git。（Codex）

## 快速开始

### 前置要求

- **Godot 4.7.2-stable**（Windows）
- 位置：`D:\claude project\Godot_v4.7.2-stable_win64.exe`

### 运行游戏

**最快方式**：双击项目目录中的 `启动试玩.cmd`。需要本工作区现有的 Godot 可执行文件，当前不是独立打包版本。

在编辑器中运行：
1. 打开 Godot，导入本目录的 `project.godot`。
2. 按 **F5** 运行，默认打开第一人称移动练习，点击画面开始。
3. 按 **F8** 停止并回到编辑器。运行报错时查看底部“调试器 / 错误”并保留错误信息。

### 第一人称战斗试玩操作

| 按键 | 功能 |
|---|---|
| `W A S D` | 相对镜头方向移动，默认奔跑；没有方向输入时保持不动 |
| 鼠标移动 | 自由观察，不强制角色持续朝向某个目标 |
| 按住 `Shift` / `空格` | 按住走路、松开恢复奔跑 / 跳跃 |
| `Ctrl` | 按住蹲伏；高速时滑铲，空中按住可落地接滑铲 |
| 向前 + `空格` | 接近合适的矮墙或高台时攀越；头顶空间不足时不会强行站起或攀入 |
| 鼠标左键 | 近战挥击；可按住连续挥击 |
| 按住鼠标右键 | 钩爪；WASD 摆荡，松开保留惯性，起钩后立刻空格助推 |
| `1—5` / 滚轮 | 选择快捷物品位；空位不能攻击 |
| `Tab` | 调整练习刃放在哪一格；当前没有其他可用物品 |
| `F` / `G` | 五敌清怪 / 三敌机动试炼 |
| `H` | 无敌人的移动练习：滑铲穿梁 → 台阶 → 矮墙 → 高台 → 钩爪 |
| `V` | 灵动／轻型参考速度切换，左下显示当前档位；重试保留选择 |
| `R` | 满血重开当前试炼 |
| `Esc` | 释放或重新捕获鼠标；释放时停止移动 |
| 点击画面 | 鼠标释放后恢复操作 |

先在 H 沿金色标记练连续移动，查看左下速度与动作状态；V 对比前冲 8.2 m/s 的灵动档与 6.6 m/s 的轻型参考档，再用 F／G 体验攻击衔接。以《THE FINALS》的连续、可控移动为体验参考，当前参数为独立原型，不代表复刻其实现或已经达到相同手感。速度统一在 `data/combat_mvp.json` 的 `player.movement_profiles`，其余灵敏度、视野、滑铲／攀越、手部幅度与移动音量也在该文件；完整游戏内设置尚未做。钩爪保留 CodeBuddy 的 21 米与测试无冷却，绳索不绕障碍。旧场景全部保留。（Codex）

滑铲附加镜头强度由 `player.slide_camera_motion_scale` 调整：1 为当前轻量效果，0 关闭额外侧倾、起伏、后移和视野反馈，仍保留真实蹲伏碰撞及基础蹲姿高度。滑铲不会主动改变鼠标俯仰与正前方瞄准方向。完整设置面板后置。（Codex）

历史 2D 场景是 `scenes/main.tscn`，仅用于代码参考，旧空格键钓鱼和 1/2/3 回合操作不属于当前 3D 样机。

## 核心系统说明

### 历史钓鱼实现（`scripts/fishing.gd`）

**以下是旧数据与旧流程，不是现行节奏目标。** 用户已废弃长等待及长收线；新目标见 GDD 3.1.2，采用对标《泰拉瑞亚》的随机咬钩与及时收竿。当前代码和 JSON 尚未替换，不能宣称新节奏已实现。（Codex）

```
IDLE → CASTING → WAITING → BITING → REELING → RESULT → IDLE
```

- **WAITING**：随机 15-45 秒（Lv1 鱼竿），鱼漂起伏
- **BITING**：限时按键窗口（0.35-0.60 秒，随鱼竿等级放宽）
- **REELING**：收线计时，期间可能脱钩
- **RESULT**：按 50/25/15/5/3/2 概率抽取渔获

### 渔获概率分布

| 结果 | 概率 |
|---|---|
| 普通水产 | 50% |
| 垃圾 | 25% |
| 任务物品 | 15% |
| 异兽 | 5% |
| 奇异物质 | 3% |
| 剧情道具 | 2% |

### 战斗（`scripts/combat.gd`）

**目标设计**：第一人称 3D 自由实时战斗，不要求先锁定敌人，不强转镜头。先做一个敌人与一种攻击的短战斗，再逐件对比范围近战、轻度辅助直射与追踪弹，数值通过试玩调整。（Codex）

**现有实现**：实时近战由 `scripts/mvp/first_person_player.gd` 与 `melee_enemy.gd` 实现，调参在 `data/combat_mvp.json`。旧 `combat.gd` 仍是废弃的回合制原型，不被新场景调用；直射、追踪弹、掉落和制造尚待接入。（Codex）

### 炼化（`scripts/crafting.gd`）

三层配方结构：固定（60%）/ 半固定（30%）/ 隐藏（10%）。

## 贡献指南

### 代码规范

- **类型标注**：所有函数参数与返回值必须标注类型（`func foo(a: int) -> void:`）
- **注释**：每个脚本头部写模块说明；复杂逻辑写行内注释
- **命名**：变量与函数用 `snake_case`，类名用 `PascalCase`，常量用 `UPPER_CASE`
- **数据驱动**：新增内容优先改 JSON，不要把数值硬编码进脚本

### 新增内容的正确做法

**新增一种鱼**：
1. 在 `data/fish_data.json` 的 `fish` 数组添加条目（必须含唯一 `id`）
2. 在 `data/water_area_data.json` 对应水域的 `fish_pool` 中引用该 `id`
3. 运行游戏验证能被钓到

**新增一种异兽**：
1. 在 `data/monster_data.json` 添加条目（含 `hp` / `attack` / `defense` / `drops`）
2. 在对应水域的 `monster_pool` 中引用
3. 掉落表的 `rate` 之和建议不超过 1.0

**新增一个配方**：
1. 在 `data/recipe_data.json` 添加条目
2. `type` 可选 `fixed` / `semi` / `hidden`
3. `materials` 的 key 必须是 `item_data.json` 中存在的 `id`

**新增一个脚本**：
1. 放在 `scripts/` 下
2. 首行写 `extends <基类>`，需要全局类型时加 `class_name`
3. 顶部用 `##` 写模块说明（Godot 会显示在文档中）
