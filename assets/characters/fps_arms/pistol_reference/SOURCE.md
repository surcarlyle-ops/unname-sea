# 单手手枪动作参考
来源：https://github.com/bukkbeek/GodotFPS-Template ，作者 bukkbeek。
本地 resources/player/fps_demo_arms.glb；实际含 pistol_fire / pistol_reload。
根 LICENSE 为MIT，原README另注明禁止单独转售项目来源资产；保留此声明。不把代码MIT许可推断为所有第三方素材许可。本次只用作者声明自制的手臂/手枪动作，没有复制音效/VFX/怪物。
使用 pistol_fire t=0 的骨骼姿势作为迁移起点，按解剖掌面变换，2节源指骨分配至目标3节；目标拇指接触另行修正。不是把原手替换到主角，也不是完整换弹动画迁移。
当前仅独立预览；源手枪黑色材质取自原资源。用户验收待定。（Codex）
