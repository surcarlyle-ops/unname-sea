### 轻型移动对照与下一轮调整（2026-10-21）

用户明确以《THE FINALS》轻型的灵活、机动体验为参照。改动已接入 F3；新增默认奔跑／按住 Shift 走路及滑铲镜头，移动 63 项＋战斗 40 项通过，实机截图已检视，待用户判断手感。尚未进行两款游戏的同路线实机测量。（Codex）

**已核实的参考：**

- 官方 2026-10-20 更新后，轻型冲刺前进／横移／后退分别为 **6.6／4.4／3.7 m/s**，普通跑动为 **5.1／4.2／3.7 m/s**；更新前前冲为 7.0 m/s。它支持各方向冲刺，但各方向速度不同。[当前数值](https://www.reachthefinals.com/patchnotes/12-00)、[全方向冲刺说明](https://www.reachthefinals.com/patchnotes/200)。（Codex）
- 近期轻型降速涉及多人队伍的移动速度差与团队凝聚，不直接作为本项目必须降速的理由。[设计负责人解释](https://www.reachthefinals.com/patchnotes/respec-order-3-retrospective)。（Codex）
- 官方曾降低滑铲触发所需速度，明确目的是更容易进入滑铲；另持续改善蹲伏转向、滑铲到站立／跑动的动画，以及楼梯／碎屑上的滑铲音效。[10.3.0](https://www.reachthefinals.com/patchnotes/10-30)、[9.9.0](https://www.reachthefinals.com/patchnotes/990)。这些记录未公开完整摩擦、空中操纵或攀越算法。（Codex）

**调研问题与本轮结果：**

| 优先级 | 调研时发现的问题 | 已实现与待验证体验 |
|---|---|---|
| P0 起停与转向 | 各方向冲刺均为 8.2 m/s；普通刹车与超速减速共用分支，松开 Shift 改变减速行为 | 已分离普通刹车、反向加速与外部动量，方向速度使用椭圆混合避免斜向加速；钩爪核心及松钩宽限保留。体验仍待验收 |
| P1 滑铲衔接 | 入口 ≥5.5 m/s；提前按 Ctrl 易变成蹲走；滑铲状态固定限时 | 已加 0.15 秒意图缓冲，入口试调为 4.8 m/s；平地仍短滑，足够下坡时可超过 1.1 秒继续滑动且限速；滑铲跳／落地接滑回归通过。这些是独立试验值 |
| P1 翻越与攀爬 | 统一先上移再前移，低障碍也有明显竖直阶段 | 已按高度区分低障碍前移弧线和高障碍上攀，时长随高度变化；新增头顶阻挡中断检查。物理路线及新增障碍检查通过 |
| P2 手部与声音 | 简单周期摆动，没有移动声 | 已按实际地面位移驱动步频，平滑冲刺／滑铲／攀爬手姿，补脚步、起跳、落地及滑铲合成占位声。正式动作、材质音色与听感后续调整 |
| P2 视野与尺度 | 当前相机基准 FOV 78；默认保持高度，16:9 下约等于水平 110.4° | 比较前统一分辨率、视野轴与人物尺度，再调世界视野和手持位置；不能把其他游戏设置的“90”直接填进 Godot |

默认奔跑只改变移动速度档，没有方向输入时不自动前行；按住 Shift 持续走路，松开即恢复跑动。滑铲视线从蹲伏 0.94 米平滑压到 0.86 米，附加约 0.55° 侧倾、最多约 2.5 毫米起伏和小幅视野变化；退出、暂停、重试清理相应状态。不改鼠标俯仰与正前方瞄准方向；`slide_camera_motion_scale=0` 可关闭额外动效。新接入的落地反馈叠加在运动模块的姿态高度上，不能再用固定站立高度覆盖头部；钩爪核心由 CodeBuddy 继续优化。（Codex）

刹车验证：修改前按代码推算，两种松键方式约为 0.35／0.62 秒停止。修改后在真实测试场以 60 Hz、平地前冲 8.2 m/s 且无钩爪宽限验证，两种方式均 **0.35 秒、约 1.33 米**停止；证据在 `.mvp_qa/motion_verification.log`。这不代表已测得《THE FINALS》的停止参数。（Codex）

视野依据：[Godot Camera3D 官方文档](https://docs.godotengine.org/en/stable/classes/class_camera3d.html#class-camera3d-property-fov)。尚未核实《THE FINALS》当前设置滑块的视野轴；不据此声称视野已经对齐。（Codex）

**验证办法与范围：**

- 已提供 F4 切换的灵动／轻型参考档：前冲 8.2／6.6 m/s；横移 5.5／4.4、后退 4.6／3.7 m/s。默认灵动档，重试保留选择。两档共用本项目动作逻辑，参考档不等于整套轻型物理；后续按试玩定最终速度。（Codex）
- 使用 F3 的短路线，补距离标记和近景参照，连续完成“冲刺 → 转向 → 滑铲 → 跳跃 → 低障碍翻越 → 高台攀爬 → 钩爪松开 → 落地”。同路线比较停止距离、触发成功率、意外卡顿和用户偏好；先修最影响连续操作的一项。（Codex）
- 现有跳跃缓冲 0.12 秒、离地跳跃宽限 0.10 秒和约 50° 可走坡度已实现；继续检验斜向进障碍、坡面接缝与低顶，不重复当作新增功能。钩爪核心继续沿用 CodeBuddy 组件。（Codex）
- 对《THE FINALS》的精确跳跃高度、加速度、摩擦、空中转向与攀越时长暂无可靠公开原始参数。后续可用轻型实机录屏逐帧对照；本计划不声称 1:1 复刻，不引入多人联网或场景破坏作为前置条件。（Codex）
