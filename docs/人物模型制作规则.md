# 人物模型制作规则（SOP）

> **适用范围**：本项目所有 3D 角色——主角、NPC、普通怪物、BOSS。
> **性质**：规则文档。做任何角色前先读这一份，按流程走，不要跳步。
> **来源**：@斌叔OKmath 的 Tripo + GPT-6 Astra 笔记、Sac《小王子：星辰之旅》工作流、Tripo/Blender 实操教程。
> **最后更新**：2026-10-18
> **MVP 现成资产入口**：优先筛选有明确许可、带骨骼及基础动作的现有模型；可直接进入导入与动作验收，不要求先出参考图、使用 Tripo 或重新绑骨。下文的生成、拆件和白模步骤仅适用于新生成角色；保留原始下载包、来源与许可。（Codex）

---

## 一、三条铁律

| # | 铁律 | 说明 |
|---|---|---|
| 1 | **结构优先于细节** | 先看头身比例、关节、轮廓，再看贴图和特效。结构不对，贴图再美也没用 |
| 2 | **按需选择资产路线** | MVP 优先复用现成的合格角色；新生成角色再走 Tripo 流程，避免要求编程 AI 从零雕刻复杂角色。现成角色不必重走白模生成或绑骨。（Codex） |
| 3 | **问题回退到输入层** | 模型不对 → 换更干净的参考图 / 补多视图 / 改提示词。**不要硬着头皮进绑骨** |

---

## 二、两种制作模式

| | **模式 A：整体生成** | **模式 B：拆件生成** |
|---|---|---|
| 做法 | 单图/三视图 → Tripo 一次出整个角色 | 整体白模 → 智能拆件 → 头部单独处理 → Blender 组装 |
| 耗时 | 几分钟 | 数十分钟 |
| 二次元脸 | 容易崩（眼睛、手指） | 头部可反复抽，稳定 |
| 面数控制 | 不可控 | 头部可单独控制在 2000-5000 面 |
| 绑骨友好度 | 服装与身体易粘连 | 服装分层，穿模少 |
| **适用** | 占位资产、路人 NPC、MVP 验证 | 主角、BOSS、需要精细面部或换装的角色 |

### 选择标准

```
MVP 阶段 / 占位          → 模式 A
正式主角 / BOSS / 可动   → 模式 B
判断依据：是否需要精细面部？是否需要换装？是否需要复杂动作？
```

## 三、标准流程（六步）

### 步骤 1 · 准备参考图

**合格参考图的三个标准**（缺一不可）：

- [ ] 五官、发型、服装层次没有被遮住
- [ ] 手脚和主要配件完整可见
- [ ] 姿态不造成躯干与四肢互相遮挡

**输入方式选择**：

| 输入 | 什么时候用 |
|---|---|
| 单图 | 快速验证、占位角色（大多数情况够用） |
| 四视图（正/侧/背/T-Pose） | 需要锁定背面细节的正式角色 |

**四视图提示词模板**：

```
二次元风格 3D 游戏角色，<角色描述>
服装：<服装细节，强调袖口、裙摆、配件>
配色：<主色 + 辅色，低饱和>
要求：正面、侧面、背面、T-Pose 四视图，同一角色，
     背景纯白，无遮挡，手脚完整可见，五官清晰
风格：低多边形，适合 3D 游戏
```

**检查点**：同一角色在四个视图里是否变形、比例是否一致、光照方向是否冲突。**不合格先修图，不要生成模型。**

---

### 步骤 2 · Tripo 生成白模

| 参数 | 设置 |
|---|---|
| 模型 | **Smart Mesh P2.0**（面向游戏/动画，面数可控、拓扑干净） |
| 头部面数 | **2000 - 5000** |
| 输入 | 单图 或 多图（Multi Images） |
| 输出格式 | GLB（进 Godot）/ FBX（进 Blender 绑骨） |

> ⚠️ **贴图生成后不可逆**——白模阶段必须反复重抽，直到满意再贴图。

---

### 步骤 3 · 检查白模（不通过不许贴图）

**按这个顺序检查**：

```
头身比例 → 脸部朝向 → 发块分布 → 袖口/裙摆是否独立 → 双手是否完整 → 鞋底是否成型
```

**二次元角色最该复查的 4 个部位**：

| 部位 | 检查标准 |
|---|---|
| **脸** | 正面/侧面都对称 |
| **头发** | 发束之间有分离，不糊成一团 |
| **手指** | 五指可辨，不是"连指手套" |
| **服装边缘** | 袖口/裙摆独立成层，不与身体粘连 |

**眼睛专项**（模式 B 必查）：

- [ ] 眼窝正确凹陷
- [ ] 瞳孔独立

> 达不到就继续抽，Tripo 免费可以反复重生成。

---

### 步骤 4 · 贴图

- 白模验收通过后才点 Texture
- 贴图后不能再重新生成模型，所以这是**单向门**
- 贴图分辨率按目标平台预算（PC 可高，移动端要压）

---

### 步骤 5 · 绑骨与蒙皮

**前提**：模型必须是 **T-Pose 或 A-Pose**。姿态离标准太远会导致肩膀反折、肘部不自然、腿部拉扯、服装穿插。

**绑骨提示词模板**：

```
使用 T-Pose 完成自动绑骨和蒙皮。
先对齐肩、肘、腕、髋、膝、踝，再测试抬手、弯腿、转身三个动作。
逐项检查：肩部塌陷、膝盖拉扯、衣物穿模、脚底滑动。
发现问题只修改对应权重或骨骼，不要改变角色比例。
```

**检查清单**：

- [ ] 骨骼与关节对齐
- [ ] 抬手无肩部塌陷
- [ ] 弯腿无膝盖拉扯
- [ ] 转身无衣物穿模
- [ ] 脚底无滑动

---

### 步骤 6 · 接动作

**顺序**：先基础动作，再复杂动作。

```
待机 idle → 行走 walk → 跑步 run → 抬手 → 攻击 attack
```

**动作来源**：Mixamo（免费，需检查骨骼映射）。

> ⚠️ Mixamo 预览正常 ≠ 引擎里正常。导入后必须检查 Avatar、根骨骼、碰撞。

**复杂接触动作**（如握持道具）：

```
参考提供的基础动作，保留下肢和躯干节奏，
用 IK 调整手臂姿势，并同步修正手指握持和道具位置。
要求手掌与把手持续接触，抬起过程中不穿模、不脱手、不悬空。
导出前分别检查起始帧、中间帧和结束帧。
```

## 四、高风险部位预警

以下部位在建模和动画阶段最容易出问题，**建模前就要决定：简化，还是单独处理**。

| 部位 | 风险 |
|---|---|
| 长发 | 发块穿插、物理抖动穿模 |
| 披风 / 大裙摆 | 绑骨后大面积穿模 |
| 翅膀 | 骨骼复杂、动作难匹配 |
| 巨大武器 | 遮挡视线、握持点难对齐 |
| 非对称配件 | 左右权重不对称 |

---

## 五、踩坑清单（必读）

| # | 坑 | 后果 | 规避 |
|---|---|---|---|
| 1 | **贴图不可逆** | 纹理生成后不能再重抽模型 | 白模阶段反复抽到满意 |
| 2 | **眼睛易崩** | 整体生成时眼睛糊成一片 | 模式 B，头部单独抽 |
| 3 | **让 AI 从零建模** | 大量崩坏模型 | 必须 Tripo 出白模 |
| 4 | **参考图不干净** | 一绑骨就扭肩、穿模 | 背景纯白、无遮挡、手脚完整 |
| 5 | **在错误层修问题** | 越修越糟 | 回退到输入层（换图/补视图/改提示词） |
| 6 | **贴图后再改结构** | 需要重做整个模型 | 结构验收通过才贴图 |

## 六、命名与归档

**命名规范**：

```
char_<角色名>_<部件>_v<两位版本>.glb
```

示例：

```
char_traveler_head_v01.glb
char_traveler_body_v01.glb
char_traveler_full_v01.glb
mon_backlight_crab_v01.glb
```

**必须保留的文件**：

- [ ] 参考图（单图或四视图）
- [ ] 使用的提示词
- [ ] Tripo 原始白模
- [ ] 清理后的模型
- [ ] 绑定文件（.blend）
- [ ] 导出文件（GLB/FBX）
- [ ] 生成日期与使用的模型版本

## 七、本项目角色对应表

| 角色 | 建议模式 | 阶段 | 说明 |
|---|---|---|---|
| 主角（旅行者） | B | MVP 先用 A 占位 | 正式版再拆件精修 |

## 八、阶段验收总表

| 阶段 | 通过标准 |
|---|---|
| **白模** | 结构正确、五指可辨、眼窝凹陷、瞳孔独立 |
| **贴图** | 颜色/材质符合设定，无拉伸 |
| **绑骨** | 关节对齐，抬手/弯腿/转身无异常 |
| **动作** | idle/walk/run 正常，无穿模、无脚滑 |
| **入引擎** | 导入 Godot 后缩放正确、材质正常、动画可播放 |
