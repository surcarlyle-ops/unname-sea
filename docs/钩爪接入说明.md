> **面向 Codex**：把 `GrappleHook` 组件接入第一人称控制器。
> 组件位置：`scripts/mvp/grapple_hook.gd`（`class_name GrappleHook`）
> 最后更新：2026-10-21（CodeBuddy）

## 一、组件职责

`GrappleHook` **只做三件事**：

1. 发射（射线检测，21 米）
2. 附着后**接管角色的水平速度**
3. 释放时保留动量 + 按距离计算冷却

它**不改**角色的重力、跳跃、碰撞、输入。

---

## 二、接入步骤

### 1. 挂节点

在 `Player`（CharacterBody3D）下加一个 `Node3D`，挂 `grapple_hook.gd`。

### 2. Player 需要处理输入

```gdscript
@onready var grapple: GrappleHook = $GrappleHook

func _unhandled_input(event: InputEvent) -> void:
    if event is InputEventMouseButton:
        var button := event as InputEventMouseButton
        if button.button_index == MOUSE_BUTTON_RIGHT:
            if button.pressed:
                grapple.try_attach()
            else:
                grapple.release()
```

### 3. 移动逻辑要避让

钩爪附着时，**水平速度由钩爪接管**，Player 只保留轻微空中转向：

```gdscript
func _physics_process(delta: float) -> void:
    var input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
    var direction := (transform.basis * Vector3(input.x, 0.0, input.y)).normalized()

    if grapple.is_attached():
        # 钩爪接管水平速度，只允许轻微转向
        velocity += direction * air_steer * delta
    else:
        # 正常移动逻辑
        var target := direction * move_speed
        velocity.x = move_toward(velocity.x, target.x, accel * delta)
        velocity.z = move_toward(velocity.z, target.z, accel * delta)

    # 重力和跳跃照常
    ...
```

### 4. 跳跃时触发超级钩

```gdscript
if Input.is_action_just_pressed("jump"):
    if is_on_floor():
        velocity.y = jump_velocity
    elif grapple.is_attached():
        grapple.apply_super_grapple()
```

### 5. 死亡 / 重试

```gdscript
func respawn() -> void:
    grapple.reset()
```

## 三、接口清单

| 方法 / 属性 | 用途 |
|---|---|
| `try_attach() -> bool` | 发射，返回是否命中 |
| `release()` | 主动松开（保留动量） |
| `reset()` | 死亡 / 重试重置 |
| `is_attached() -> bool` | 是否附着中 |
| `is_ready() -> bool` | 是否可再次发射 |
| `can_attach() -> bool` | 当前准星方向能否钩中（**给准星每帧调用**） |
| `apply_super_grapple() -> bool` | 超级钩冲量 |
| `cooldown_ratio() -> float` | 冷却进度 0..1（给 HUD） |
| `state` | `IDLE` / `ATTACHED` / `COOLDOWN` |

## 四之二、钩爪2 配套手感（`data/combat_mvp.json`）

钩爪2 的体验由钩索 + 移动系统共同决定，以下参数不在 `grapple_hook.gd` 里，而在玩家配置中。

### 重力与坠落

| 参数 | 值 | 说明 |
|---|---|---|
| `gravity` | 22.0 | 基础重力（m/s²） |
| `gravity_rising_scale` | 1.0 | 上升阶段重力倍率，1.0 = 纯自然重力 |
| `gravity_falling_scale` | 1.0 | 下落阶段重力倍率 |
| `gravity_apex_scale` | 1.0 | 顶点（垂直速度 < 窗口）倍率，1.0 = 无滞空 |
| `gravity_apex_window` | 2.2 | 顶点判定窗口（m/s） |
| `terminal_velocity` | 26.0 | 终端下落速度，超过后不再加速 |
| `terminal_soft_zone` | 8.0 | 接近终端速度时重力衰减的区间 |
| `jump_speed` | 7.0 | 起跳初速，跳高约 1.11 米 |
| `air_acceleration` | 14.0 | 空中水平控制（"轻"的来源） |

### 落地僵直

| 参数 | 值 | 说明 |
|---|---|---|
| `landing_dip_light` / `medium` / `heavy` | 0.02 / 0.07 / 0.10 | 三档视线下沉（米） |
| `landing_recovery_medium` | 0.10 | 中落（9-20 m/s）僵直秒数 |
| `landing_recovery_heavy` | 0.20 | 重落（>20 m/s）僵直秒数，期间禁跳 |
| `landing_recovery_speed_scale` | 0.55 | 僵直期间水平速度上限比例 |

### 空中攀爬

| 参数 | 值 | 说明 |
|---|---|---|
| `mantle_max_height` | 2.20 | 可翻越的最大高度（钩爪平台基本都能上） |
| `mantle_reach` | 1.35 | 向前探测墙面的距离 |
| `mantle_min_height` | 0.45 | 低于此高度不算翻越（走台阶） |

**触发规则**：空中按前进贴墙即攀爬，不需要按空格；挂钩状态下同样允许，翻越成功后自动 `release()` 松钩。

## 五、已知限制

1. **绳索和钩头是程序生成的占位模型**，正式美术后替换
2. **没有音效**（发射、命中、释放都需要补）
3. **侧向摆荡依赖相机朝向**，第一人称下效果明显；若改第三人称需重调
4. **只能钩 StaticBody3D / RigidBody3D**，不能钩玩家或 Area3D
5. **冷却按绳长计算**，不是按实际飞行距离（APEX 是按位移距离）
6. **没有钩头飞行动画**，命中瞬间直接出现在锚点

## 七、调试建议

| 问题 | 先调哪个参数 |
|---|---|
| 钩不到 | `max_range` |
| 拉得太猛 | `pull_speed_max` / `pull_accel_duration` ↓ |
| 起步太突兀 | `pull_delay_near` / `pull_delay_far` ↑ |
| 摆荡太飘 | `swing_damping` ↑ |
| 摆荡太沉 | `swing_damping` ↓ / `pull_speed_max` ↑ |
| 侧向不灵 | `swing_side_force` ↑ |
| 冷却太长 | `min_cooldown` / `max_cooldown` |
| 高空坠落太"砸" | `terminal_velocity` ↓（玩家配置） |
| 落地僵直太明显 | `landing_recovery_*` ↓ / `landing_recovery_speed_scale` ↑ |
| 爬不上平台 | `mantle_max_height` / `mantle_reach` ↑（玩家配置） |
